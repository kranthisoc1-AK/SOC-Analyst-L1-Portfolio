# Email Phishing Analysis and Investigation

## Project Overview
This project focuses on analysing a simulated phishing email to understand common email-based cyber threats. The investigation involves examining suspicious email characteristics, analysing URLs and attachments, reviewing email authentication mechanisms, and documenting Indicators of Compromise (IOCs).

## Objectives
- Identify phishing email characteristics.
- Analyse suspicious sender addresses and email subjects.
- Investigate suspicious URLs and attachments.
- Understand SPF, DKIM, and DMARC email authentication.
- Identify and document Indicators of Compromise (IOCs).

## Tools & Technologies
- VirusTotal
- DNSChecker
- Windows 11
- Email Header Analysis
- Web Browser
- Cybersecurity Analysis Techniques

## Investigation Activities
- Created and examined a simulated phishing email.
- Analysed suspicious sender information.
- Investigated the email subject and message content.
- Examined a suspicious URL.
- Reviewed a simulated HTML attachment.
- Studied SPF, DKIM, and DMARC authentication results.
- Prepared an IOC table.
- Documented investigation findings.

## Key Findings
- Identified suspicious characteristics commonly associated with phishing emails.
- Examined potentially malicious URL and attachment indicators.
- Reviewed email authentication mechanisms.
- Documented relevant IOCs for investigation.
