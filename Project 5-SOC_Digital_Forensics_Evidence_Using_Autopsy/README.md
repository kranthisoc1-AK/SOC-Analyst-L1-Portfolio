# Digital Forensic Investigation Using Autopsy

## Project Overview
This project focuses on digital forensic investigation using Autopsy, an open-source digital forensics platform. The objective is to examine forensic disk images, analyse digital evidence, identify relevant files and artifacts, and understand the forensic investigation process.

## Objectives
- Perform digital forensic analysis using Autopsy.
- Examine forensic disk images.
- Identify and analyse files and digital artifacts.
- Understand file system evidence and metadata.
- Document investigation findings.

## Tools & Technologies
- Autopsy 4.22.1
- Windows 11
- Digital Forensic Disk Image
- Computer Forensics

## Investigation Activities
- Created a forensic investigation case in Autopsy.
- Added a forensic disk image as an evidence source.
- Performed forensic image processing.
- Examined extracted files and digital artifacts.
- Reviewed available forensic evidence.
- Documented investigation observations.

## Key Learning Outcomes
- Understanding digital forensic investigation workflows.
- Working with forensic disk images.
- Identifying relevant digital evidence.
- Using Autopsy for forensic examination.
- Preparing forensic investigation documentation.
