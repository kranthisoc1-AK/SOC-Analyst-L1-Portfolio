## 1. Project Overview

The objective of this project was to configure Active Directory security auditing, monitor user and group activities, detect suspicious authentication attempts, and investigate security events using Windows Security Event Logs.

The project simulates common SOC Analyst Level 1 responsibilities in a Windows domain environment.

## 2. Project Objectives

- Configure an Active Directory domain environment.
- Implement password and account lockout policies.
- Enable advanced Windows security auditing.
- Monitor failed login attempts.
- Detect user account creation, deletion, modification and password changes.
- Monitor security group membership changes.
- Investigate security events using Event Viewer.
- Prepare security investigation findings and evidence.

## 4. Module 1 – Active Directory Setup

Configured the Active Directory environment.

Activities:
- Installed and configured Active Directory Domain Services.
- Created the domain `soclab.local`.
- Configured the Domain Controller.
- Created the `SOC_Users` Organizational Unit.
- Created and managed domain user accounts.
- Verified Active Directory user and organizational unit configuration.

## 5. Module 2 – Password Policy and Account Lockout

Configured the Default Domain Password Policy.

| Policy | Configuration |
|---|---|
| Minimum password length | 10 characters |
| Password complexity | Enabled |
| Account lockout threshold | 5 attempts |
| Account lockout duration | 15 minutes |
| Observation window | 15 minutes |

**Testing limitation:** The account lockout configuration was verified, but the expected lockout behavior was not successfully demonstrated. The `rahul.sharma` account showed `BadPwdCount = 3` and `LockedOut = False` during testing.

Further validation is required.

## 9. Module 6 – Security Investigation

Used Windows Event Viewer to investigate authentication, account management and security group activities.

Investigation activities:

1. Reviewed failed login events.
2. Investigated user account creation and deletion.
3. Reviewed password change and reset events.
4. Investigated user account modifications.
5. Reviewed security group membership changes.
6. Inspected event details, including Subject, Target Account, Group Name and timestamps.

### Investigation Findings

The lab demonstrated how Windows Security Event Logs can be used to identify account and group management activities.

Potential security concerns include:
- Repeated failed login attempts.
- Unexpected user account creation.
- Unauthorized password resets.
- Unexpected account modifications.
- Unauthorized membership changes in privileged groups.

All findings should be correlated with the expected lab activity before being classified as suspicious.

## 12. Limitations

- Account lockout after five failed attempts was configured but not successfully demonstrated.

- Local security group monitoring was not demonstrated in the Domain Controller environment.
- The project used a controlled virtual lab rather than a production Active Directory environment.

## 13. Conclusion

This project provided practical experience in Active Directory administration, Windows security auditing, authentication monitoring, user account management and security group monitoring.

It demonstrated how a SOC Analyst Level 1 can use Windows Security Event Logs to investigate authentication failures, account changes and privilege-related activities.

The project also provided hands-on experience with Group Policy, PowerShell and Windows Event Viewer, strengthening practical skills required for entry-level Security Operations Center roles.
