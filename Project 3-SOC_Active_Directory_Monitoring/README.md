# Active Directory Security Monitoring and Investigation

## Project Overview
This project focuses on Windows Active Directory administration, security auditing, and monitoring of domain-related activities in a controlled virtual lab environment. The objective is to understand user account management, security groups, authentication events, and security-related changes.

## Objectives
- Understand Active Directory domain environments.
- Manage domain user accounts and security groups.
- Configure Windows security auditing.
- Monitor authentication activities.
- Investigate failed login attempts.
- Understand account and privilege-related changes.

## Tools & Technologies
- Windows Server
- Active Directory Domain Services (AD DS)
- Windows Security Event Viewer
- Group Policy Management
- PowerShell
- Oracle VirtualBox

## Practical Activities
- Set up a Windows Server virtual lab.
- Worked with Active Directory domain users.
- Explored user accounts and security groups.
- Configured Windows security auditing policies.
- Monitored successful and failed authentication events.
- Examined Windows Security Event ID 4625.
- Explored account and password-related auditing.
- Investigated security-related account and privilege changes.

## Key Learning Outcomes
- Understanding Active Directory environments.
- Domain user and security group management.
- Windows authentication monitoring.
- Security audit policy configuration.
- Investigating Windows security events.
- Understanding privilege-change monitoring.
